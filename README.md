## ✨ 개요

#### 서비스명 : StackFlow ( 재고관리 사이트 )

#### 한줄 설명 : `본사와 매장이 함께 쓰는 통합 재고관리 시스템`

#### 프로젝트 기간 : 2025.01.05 ~ 2025.06.30


## ✨ 프로젝트 소개

📦 StackFlow
입출고 이력 관리, 매장 간 재고이동, 공지사항 & 실시간 채팅까지, <br>
복잡한 엑셀 정리는 **이제 그만!** <br>
**StackFlow는 본사와 다지점 재고를 효과적으로 통합 관리할 수 있는 올인원 재고관리 서비스**입니다.

🌟 StackFlow만의 특별함
- 매장 간 실시간 재고이동 (RT)
- 입출고 요청 및 처리
- 매장 코드 기반 인증
- 상품 등록 및 조회 기능
- 공지사항 기능
- 실시간 채팅 기능
